Install it

  1. Open the downloaded .dmg

    It is in your Downloads folder.

  2. Drag cowork to Applications

    Then eject the disk image.

  3. Open cowork and add a model

    Any OpenAI-compatible or Anthropic-style endpoint works. Your key stays on this computer.

Opens without a warning

The macOS builds are signed with a Developer ID and notarized by Apple, so Gatekeeper lets them through. When cowork first controls another app, macOS asks for Accessibility permission. That prompt is expected.

  1. Run the downloaded setup file

    It installs for your user account and needs no administrator rights.

  2. Let it past SmartScreen

    Choose More info, then Run anyway.

  3. Open cowork and add a model

    Any OpenAI-compatible or Anthropic-style endpoint works. Your key stays on this computer.

Why Windows shows a warning

The Windows installers are not code-signed yet, so SmartScreen does not recognize the publisher. The files come straight from our release page, and their checksums are in latest.yml next to them.

Already installed?

From version 0.8.4 on, cowork finds new versions on its own, shows you what changed, and installs them when you say so or when you quit.

Version 0.8.3 and earlier cannot find updates. Install the current version once from this page, and you are set.
