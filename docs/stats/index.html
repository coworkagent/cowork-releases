How to read this

From version 0.8.5 on, cowork checks for updates at most once every 24 hours per machine, and each check downloads one small file from the latest release. The daily increase of that file's download counter is therefore close to the number of machines that ran cowork that day. Earlier versions check more often and inflate the figure a little until they are updated.

It is a trend, not a head count. Pressing "check for updates" by hand adds a check. Machines that cannot reach GitHub, or that have automatic updates turned off, are not counted at all. It cannot tell whether today's machines are the same ones as yesterday's.
