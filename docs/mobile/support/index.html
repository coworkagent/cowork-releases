Support

Get connected, recover a permission, or tell us what went wrong.

Effective September 29, 2026

Start here

Cowork Agent is the iPhone and iPad companion for desktop Cowork. Install the latest desktop release on macOS 13 or later, or Windows 10 or later. The iOS app requires iOS or iPadOS 16.4 or later. Keep both devices on the same local network and keep the computer awake with Cowork running. See the step-by-step guide below.

Cannot scan or connect?

Allow Camera and Local Network for Cowork in iOS Settings. If you declined a permission, enable it there, return to the app and try again. Generate a fresh pairing invitation on the computer if the old one expired. Guest Wi-Fi, client isolation, a VPN or a firewall can prevent devices from reaching each other. Use a trusted local network and check that Cowork is permitted through the computer firewall.

Connected, but no tasks or files?

Check the projects and permissions granted to this device in desktop Cowork. File browsing needs file access for the current session. To send AI tasks, configure a working model on the computer and select it for the session. A sleeping or offline computer cannot accept new commands; reconnect after it is available again.

Report a problem

Use the public GitHub issue tracker for reproducible product problems. Include the iOS/iPadOS version, device model, app version and build from Settings, desktop version, steps and the exact error. Issues are public: redact names, paths and screenshots, and never post keys, pairing codes or private conversations.

Privacy and data removal

For privacy questions, read the policy and its removal steps. Removing a paired computer on the phone clears its local association; revoke the phone in desktop Cowork as well. Files saved to another app and conversations on the computer must be managed separately.

支持与反馈

连接电脑、恢复权限，或告诉我们遇到的问题。

生效日期：2026 年 9 月 29 日

从这里开始

Cowork Agent 是桌面版 Cowork 的 iPhone 与 iPad 配套应用。请在 macOS 13 或更新系统，或 Windows 10 或更新系统安装最新桌面版。iOS App 需要 iOS 或 iPadOS 16.4 或更新系统。两台设备需要处于同一局域网，电脑保持唤醒且 Cowork 正在运行。下方使用说明提供完整步骤。

无法扫码或连接？

在 iOS 设置中允许 Cowork 使用相机和本地网络。拒绝权限后，可以在设置中重新开启，返回 App 再试。配对邀请过期时，请在电脑上重新生成。访客 Wi-Fi、设备隔离、VPN 或防火墙可能阻止设备互通。请使用可信的局域网，并检查电脑防火墙是否允许 Cowork 连接。

已连接，却没有任务或文件？

检查桌面 Cowork 为该设备授权的项目和权限。浏览文件需要当前会话对应的文件访问权限。发送 AI 任务前，请在电脑上配置可用模型并为会话选中它。电脑休眠或离线时无法接收新指令；恢复后重新连接即可。

报告问题

可通过 GitHub 的公开问题区报告可复现的产品问题。请附上 iOS/iPadOS 版本、设备型号、设置中的 App 版本与构建号、桌面版本、复现步骤及完整错误文字。问题区是公开的：请遮盖姓名、路径和截图中的私人内容，切勿发布密钥、配对码或私人会话。

隐私与数据删除

如有隐私问题，请阅读隐私政策及删除步骤。在手机上移除配对电脑可以清除本地关联；也请在桌面 Cowork 中撤销手机权限。保存到其他 App 的文件及电脑上的会话需要分别管理。
