Get started with Cowork Agent

A short guide for your first connection—and for App Review.

Effective October 2, 2026

1. Prepare your computer

Download the latest Cowork desktop app from our download page and install it on your Mac or Windows PC. Open it and configure your chosen model endpoint, model name and credentials in Settings. Verify that a simple conversation works on the computer. You can use a compatible locally hosted model or a service you already use; the iOS app does not include model credits.

2. Pair on the same network

Connect the computer and iPhone or iPad to the same trusted local network. In desktop Cowork Settings, open Remote control, enable the service and create a pairing invitation. In Cowork Agent, choose Add new computer and scan that QR code. Allow Camera and Local Network when iOS asks. Compare the confirmation code on both devices, then approve the device and select the projects and permissions on the computer. Keep invitations private.

For access outside the local network, configure a relay on the computer and import the phone registration through Computers & connections → Internet relay. Use a compatible desktop release and iOS or iPadOS 17 or later. Pairing, computer permissions and certificate checks still apply. You provide the relay; Cowork does not include a hosted relay service.

3. Try a small task

On the phone, review the data-sharing explanation and the model connections reported by your computer. Check the actual services and policies on the computer, then agree if you wish to continue. You can withdraw permission and open the privacy policy in Settings. Create an empty folder on the computer, add it as a Cowork project and grant the phone access. On the phone, open that project and start a task such as: “Write a short checklist for organizing this project in README.md. Ask me before changing a file.” Read the response, handle any approval that appears, then open Files & changes to inspect the result. AI responses depend on your configured model.

4. Continue the work

Return to the session list to resume a conversation, answer a pending question, or switch between paired computers. In a conversation, attach a selected photo or file; supported results can be previewed or shared. Tasks execute on the paired computer, so it must stay awake and running. Mobile access is limited to the permissions granted there.

Notes for App Review

There is no Cowork username/password account to sign into. QR pairing with the reviewer’s own Mac or Windows PC is the connection step. The iOS app provides a native interface to conversations, task progress, approvals and authorized project files; it is not a general-purpose screen-mirroring app. Direct connection requires desktop Cowork on the same LAN. An independently configured relay can provide remote access, but no shared developer computer or official hosted relay is included. Model-backed task execution requires a model configured on that computer. Please contact the developer through the private review contact in App Store Connect if your review environment needs assistance.

开始使用 Cowork Agent

第一次连接的简明指南，也供 App 审核人员参考。

生效日期：2026 年 10 月 2 日

1. 准备电脑

从下载页面获取最新桌面版 Cowork，安装到 Mac 或 Windows 电脑。打开后，在设置中配置所选模型的接口地址、模型名称与凭据，先确认电脑上能够正常进行简单对话。可以使用兼容的本地模型或已有模型服务；iOS App 不包含模型额度。

2. 在同一网络中配对

将电脑与 iPhone 或 iPad 连接到同一可信局域网。在桌面 Cowork 设置中打开“远程控制”，启用服务并创建配对邀请。在 Cowork Agent 中选择“添加新电脑”，扫描二维码，并在 iOS 提示时允许相机和本地网络。核对两台设备显示的确认码，然后在电脑上批准设备并选择项目和权限。请勿公开配对邀请。

在局域网外连接时，请在电脑上配置中继，并通过手机的“电脑与连接 → 互联网中继”导入手机登记。需要兼容的桌面版本及 iOS 或 iPadOS 17 或更新系统。配对、电脑权限与证书验证仍然适用。中继由你自行提供，Cowork 不包含托管中继服务。

3. 体验一个简单任务

先在手机上查看数据共享说明和电脑报告的模型连接，核对电脑上的实际服务及政策，愿意继续时再同意。你可以在设置中撤回授权或打开隐私政策。在电脑上新建一个空文件夹，将其添加为 Cowork 项目并授权手机访问。在手机中打开项目，发起任务，例如：“请在 README.md 中写一份简短的项目整理清单，修改文件前先征求我的同意。”阅读回复，处理出现的审批，然后打开“文件与变更”查看结果。AI 回复取决于你配置的模型。

4. 继续处理工作

返回会话列表继续已有对话、回答待处理问题，或切换已配对电脑。在会话中可以添加选中的照片或文件，预览或分享支持的结果。任务在已配对电脑上执行，因此电脑需要保持唤醒和运行。移动端访问范围由电脑端授予的权限决定。

供 App 审核人员参考

无需登录 Cowork 用户名或密码账号，连接步骤是与审核人员自己的 Mac 或 Windows 电脑进行二维码配对。iOS App 提供会话、任务进度、审批和授权项目文件的原生界面，并非通用屏幕镜像应用。直连需要在同一局域网内运行桌面版 Cowork。自行配置中继后可以远程访问，但应用不包含共享的开发者电脑或官方托管中继。执行 AI 任务需要在该电脑上配置模型。如审核环境需要协助，请通过 App Store Connect 中的私有审核联系方式联系开发者。
